# Computed the object used to modify the environmental variables trough the simulation

Computed the object used to modify the environmental variables trough
the simulation

## Usage

``` r
get_modifiers(space, all_species)
```

## Arguments

- space:

  the space of the current time-step

- all_species:

  the list of species at the current time-step

## Value

a modifier object. It can by of any class.
