# Provides the default gen3sis2 plot aesthetics for raster spaces

Provides the default gen3sis2 plot aesthetics for raster spaces

## Usage

``` r
raster_plot_aesthetics(space, col, x_breaks, y_breaks, title)
```

## Arguments

- space:

  a space to plot the values onto

- col:

  corresponds to the raster col plot parameter. This can be omitted and
  colors are handled by raster::plot

- x_breaks:

  numeric. Break points of the x axis. Aesthetic only.

- y_breaks:

  numeric. Break points of the y axis. Aesthetic only.

- title:

  a string with plot title

## Value

no return value, called for plot
