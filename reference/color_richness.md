# Define richness color scale which is colour-vision deficient and colour-blind people safe based on scientific colour maps by Fabio Crameri

Define richness color scale which is colour-vision deficient and
colour-blind people safe based on scientific colour maps by Fabio
Crameri

## Usage

``` r
color_richness(n)
```

## Arguments

- n:

  corresponds to the
  [colorRampPalette](https://rdrr.io/r/grDevices/colorRamp.html)
  parameter

## Value

returns a [colorRampPalette](https://rdrr.io/r/grDevices/colorRamp.html)
function with the gen3sis richness colors
